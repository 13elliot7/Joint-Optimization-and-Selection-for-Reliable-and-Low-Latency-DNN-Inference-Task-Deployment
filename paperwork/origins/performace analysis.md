\subsection{Metrics and Comparison Method}
\noindent
The following metrics are used to evaluate the performance of the proposed algorithms.\par
\textbf{Hypervolume value}: The hypervolume, representing the multidimensional volume enclosed by the solution set within the target space relative to a predefined reference point, serves as a metric to evaluate the efficacy of the solution set. A greater hypervolume value, especially when minimizing the objective function, indicates a superior solution set. This suggests that the solution set covers a broader target space and gravitates towards boundaries. The calculation method for hypervolume value is given as
\begin{equation}
\label{eq20}
I_{Hv}(W)=\prod^m_{j=1}|r_j-w_j|.
\end{equation}
Here, $I_{Hv}(W)$ represents the hypervolume value of the solution set space, which is dominated by set $W$ and has a reference point $r = (r_1,r_2,...,r_m)\in R^m$. The hypercube volume for a single solution $W$ can be obtained by calculating the product of the side lengths of all dimensions.\par
\textbf{Average service reliability}: The average probability of providing reliable services of the deployed DNN inference tasks, used to evaluate the service reliability of deployed DNN inference tasks.\par
\textbf{Average accuracy reliability}: The average probability of providing accurate results of the deployed DNN inference tasks, used to evaluate the accuracy reliability of deployed DNN inference tasks.\par
\textbf{Average inference delay}: The average execution delay of deployed DNN inference tasks, used to evaluate the delay performance of deployed DNN inference tasks.\par
\textbf{The number of failed deployments}: The number of the DNN inference tasks that were not successfully deployed, used to evaluate the algorithm's ability to successfully deploy DNN inference tasks while optimizing objectives.\par
\textbf{Average running time}: Used to evaluate the time efficiency of the algorithm in generating solutions for deploying DNN inference tasks.\par
Firstly, to assess the effectiveness of the proposed method in terms of the Pareto solution set, we compare the frontiers of the Pareto solution set generated by the proposed RDODA, random deployment algorithm (RDA), and simulated annealing algorithm (SAA) in a three-dimensional view composed of service reliability, accuracy reliability, and inference delay.\par
Secondly, to evaluate the performance of the proposed method in deploying DNN inference tasks, we compared the RDODA and DSSA algorithms with reliability-aware task scheduling scheme with a bandit learning algorithm (RTBL) \cite{ref9}, random deployment algorithm (RDA), load balancing deployment algorithm (LB), and local first deployment algorithm (LPD) in terms of service reliability, accuracy reliability, and inference delay. Furthermore, we also evaluate the average running time and the number of failed deployed DNN inference tasks across these five methods under varying numbers of DNNs.
